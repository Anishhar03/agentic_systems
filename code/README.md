# Code Examples

This folder contains educational, dependency-light Python examples for the agentic AI concepts in the notes.

Run examples from this folder:

```bash
cd code
python examples/01_langchain_style_chain.py
python examples/07_langgraph_sequential.py
python examples/13_tool_calling_agent.py
```

The examples intentionally avoid real API keys. Replace `FakeLLM` with a real provider only after you understand the control flow, state, and validation boundaries.
